# \# AI Prompt History Analyzer

# 

# \## Overview

# 

# AI Prompt History Analyzer is a Java console application for storing and managing AI prompts.

# 

# The application allows users to:

# \- Add new prompts

# \- View all saved prompts

# \- Search prompts by keyword

# \- Delete prompts

# \- Display statistics

# \- Save prompts to a text file

# \- Load prompts automatically on startup

# 

# \---

#
